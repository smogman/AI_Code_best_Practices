This course covers the features that separate Claude Code power users from everyone else. None of it is required for basic use, but each one meaningfully extends what you can do.

## Lessons

1. [Hooks](/AI_Code_best_Practices/202/hooks/): Automate quality gates that run before and after Claude's actions
2. [Skills](/AI_Code_best_Practices/202/skills/): Create your own slash commands for workflows you repeat
3. [MCP Servers](/AI_Code_best_Practices/202/mcp-servers/): Connect Claude to external tools: databases, APIs, browsers
4. [Multi-Agent Basics](/AI_Code_best_Practices/202/multi-agent-basics/): Spawn subagents to work in parallel or in isolation

## Prerequisites

Complete 201. You should be running Claude on real projects with verification loops in place.

## What You'll Be Able to Do

- Run security checks automatically on every file Claude edits
- Create `/fix-issue`, `/code-review`, and other custom commands for your team
- Let Claude query your database, search GitHub, or control a browser
- Split large tasks across parallel agents without polluting a single context
