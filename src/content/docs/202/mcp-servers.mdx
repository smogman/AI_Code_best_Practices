## What MCP Is

MCP (Model Context Protocol) is a standard that lets Claude connect to external tools and data sources. An MCP server exposes capabilities — querying a database, searching GitHub, controlling a browser — that Claude can use mid-session.

Without MCP: Claude works only with your local files.  
With MCP: Claude can query your production DB schema, search your issue tracker, or screenshot a live page.

## Configuration

MCP servers are configured in `.mcp.json` in your project root:

```json
{
  "mcpServers": {
    "server-name": {
      "command": "npx",
      "args": ["-y", "@some/mcp-server"],
      "env": {
        "API_KEY": "${MY_API_KEY}"
      }
    }
  }
}
```

**Important:** `.mcp.json` often contains API keys. Add it to `.gitignore`. Use environment variable references (`${VAR_NAME}`) and keep actual secrets out of the file.

## Commonly Used MCP Servers

### PostgreSQL (read-only)
```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "POSTGRES_CONNECTION_STRING": "${DATABASE_URL}"
      }
    }
  }
}
```

Claude can now query your schema, explore table structure, and write queries. No more pasting schema docs into the chat.

### GitHub
```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}
```

Claude can read issues, PRs, and repo content directly. Useful for `/fix-issue` workflows.

### Playwright (Browser Control)
```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@executeautomation/playwright-mcp-server"]
    }
  }
}
```

Claude can open a browser, navigate to your dev server, take screenshots, and click elements. This is the verification loop for UI work.

### Filesystem (Outside Project)
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allow"
      ]
    }
  }
}
```

Gives Claude read access to directories outside your project root.

## Using MCP in Practice

Once an MCP server is configured, Claude uses it automatically when relevant. You can also ask explicitly:

```
Using the database MCP, show me the schema for the orders table.
```

```
Open my dev server in the browser and take a screenshot of the checkout page.
```

```
Find all open GitHub issues labeled "bug" and summarize them.
```

## Security Considerations

- MCP servers run with whatever permissions you give them
- A read-only DB connection is safer than read-write for most use cases
- Don't connect Claude to production systems with write access unless you understand the risk
- Review what each MCP server can do before adding it
