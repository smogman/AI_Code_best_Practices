You can use Claude Code. Now make it work significantly better. This course covers the practices with the strongest evidence behind them: the things that produce a 2-3x improvement in output quality.

## Lessons

1. [Context Management](/AI_Code_best_Practices/201/context-management/): advanced strategies for keeping sessions clean and focused
2. [Plan Mode](/AI_Code_best_Practices/201/plan-mode/): how to think before you code, and when it matters most
3. [Verification Loops](/AI_Code_best_Practices/201/verification-loops/): the #1 quality practice — giving Claude ways to check its own work
4. [Writing a Great CLAUDE.md](/AI_Code_best_Practices/201/great-claude-md/): advanced configuration for teams and complex projects

## Prerequisites

Complete 101 and 102. You should have Claude Code running on at least one real project with a `CLAUDE.md` in place.

## What You'll Be Able to Do

- Structure sessions to maintain quality across complex, multi-step tasks
- Use Plan Mode to prevent Claude from making silent architectural decisions
- Set up verification loops that let Claude catch its own bugs
- Write a `CLAUDE.md` that works well at team scale
