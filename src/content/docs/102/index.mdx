You can use Claude Code without any configuration. But configure it properly and every session gets dramatically better. Claude arrives already knowing your stack, your conventions, and what it shouldn't touch.

## Lessons

1. [CLAUDE.md Basics](/AI_Code_best_Practices/102/claude-md-basics/): what it is, what to put in it, and how long it should be
2. [Project Setup Checklist](/AI_Code_best_Practices/102/project-setup/): everything to do before your first real session
3. [Understanding the Context Window](/AI_Code_best_Practices/102/context-window/): why sessions degrade and what to do about it

## Prerequisites

Complete 101 first. You should be comfortable starting a session and using basic slash commands.

## What You'll Be Able to Do

- Write a `CLAUDE.md` that meaningfully improves Claude's behavior on your project
- Set up a new project so Claude is immediately productive from session one
- Understand why context matters and when to reset it
