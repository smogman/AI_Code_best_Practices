This course is for people who use Claude Code daily on real production work. The patterns here are drawn from practitioners who have pushed Claude Code to its limits: high-volume agentic workflows, team-scale adoption, and cost-conscious production usage.

## Lessons

1. [Multi-Agent Architectures](/AI_Code_best_Practices/300/multi-agent-architectures/): Orchestration patterns for complex tasks: Writer/Reviewer, Factory, fan-out
2. [Advanced Patterns](/AI_Code_best_Practices/300/advanced-patterns/): SPEC pipelines, git discipline, prompt caching, auto mode
3. [Cost & Token Optimization](/AI_Code_best_Practices/300/cost-optimization/): Practical budgeting, model selection strategy, and what's actually expensive

## Prerequisites

Complete 202. You should be comfortable with subagents, hooks, and skills. This course assumes active daily use on real projects.

## What You'll Be Able to Do

- Design multi-agent systems that produce consistently higher-quality output than single-agent work
- Build workflows that scale to large codebases without context degradation
- Optimize token usage without sacrificing output quality
- Understand where Claude Code breaks down at scale and how to work around it
