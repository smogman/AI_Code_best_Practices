This course gets you from zero to productive with Claude Code. By the end you'll have the tool installed, understand how to talk to it effectively, and know the essential commands you'll use every day.

## Lessons

1. [What is Claude Code & Installation](/AI_Code_best_Practices/101/what-is-claude-code/) — What it is, how it works, how to install it
2. [Your First Session](/AI_Code_best_Practices/101/first-session/) — Starting a session, prompting patterns that work
3. [Essential Slash Commands](/AI_Code_best_Practices/101/slash-commands/) — The 10 commands you'll use constantly
4. [Understanding Permissions](/AI_Code_best_Practices/101/permissions/) — What Claude can and can't do, and why

## Who This Is For

Complete beginners. You should have a terminal and Node.js installed. That's it.

## What You'll Be Able to Do

- Start Claude Code on any project
- Have a productive back-and-forth with Claude about your code
- Use slash commands to control the session
- Understand what Claude is doing when it asks for permission
