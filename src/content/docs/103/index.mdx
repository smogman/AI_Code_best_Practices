Writing good prompts is the highest-leverage skill you can develop as a Claude Code user. A specific prompt can be 5-10x more efficient than a vague one on the same task. This course covers what makes the difference.

## Lessons

1. [The Specificity Principle](/AI_Code_best_Practices/103/the-specificity-principle/): why vague prompts are expensive and what to do instead
2. [Providing Context Effectively](/AI_Code_best_Practices/103/input-modalities/): @ file references, images, URLs, and piped data
3. [Constraints That Work](/AI_Code_best_Practices/103/designing-constraints/): how to tell Claude what NOT to do

## Prerequisites

Complete 101. You do not need a project set up yet.

## What You'll Be Able to Do

- Write prompts that point Claude directly to the right files and functions
- Use multiple input types (text, files, images, data) to give richer context
- Scope Claude's work so it makes changes in the right places and nowhere else
